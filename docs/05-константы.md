# Константы плагина

В основном файле плагина `cpm.php` определяются константы, используемые для определения режимов работы и служебных целей.

## Определённые константы

| Константа | Значение | Назначение |
| --------- | -------- | ---------- |
| `CPM_FORCE_DELETE` | `true` | Способ удаления сущностей в БД: удаление без помещения в корзину |
| `CPM_BACKWARD_COMPATIBILITY` | `true` (дефолт при наличии старых данных) | Включает чтение старых форматов данных (обратная совместимость). Подробнее: `docs/core/совместимость.md` |

## Примечания

- `CPM_FORCE_DELETE` используется в `delete_entity()` базового класса `Entity` (см. `docs/core/entity.md`).
- `CPM_BACKWARD_COMPATIBILITY` можно переопределить хуком `cpm_settings_backward_compatibility`.
- Список констант может расширяться по мере разработки.
