# Модуль расширений (Extensions)

> Спецификация минимальна: модуль заявлен в архитектуре как «Единый механизм загрузки и управления расширениями (extensions) системы для расширения её функций». Детали не описаны.

## Место в архитектуре

- Менеджер модуля: `\CPM\v3\Extensions\Extensions_Manager`, файл `CPM_PLUGIN_DIR/extensions/extensions_manager.php`.
- Создаётся в классе `Plugin` по хуку `init`.
- Расширения — способ расширения функций CPM, подключаются единым механизмом загрузки и управления.

## Как расширения взаимодействуют с ядром

- События ядра `cpm_core_entity_*` предназначены в том числе для расширений (уведомления в почту/мессенджер и т.п.). См. `docs/core/хуки-события.md`.
- Активность (журнал действий) — ключевой потребитель событий ядра: `docs/core/activity.md`.
