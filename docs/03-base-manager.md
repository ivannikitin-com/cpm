# Класс Base_Manager

Базовый класс менеджеров модулей. Реализует все общие свойства и методы всех менеджеров модулей CPM.

Назначение менеджера модуля:

- Загрузка и инициализация классов модуля.
- Управление самим модулем (включение/выключение отдельных функций модуля в зависимости от ситуации и т.п.).

## Загрузка и инициализация классов модулей

Менеджер использует **собственные механизмы загрузки классов через `require()`**, а не автозагрузку Composer или аналоги. Основная идея — экономия памяти при работе системы:

- Если модуль ядра нужен всегда, все его классы загружаются через `require()` при инициализации менеджера ядра.
- Если классы модуля UI нужны только при отображении интерфейса, они загружаются только при рендеринге страницы интерфейса или шорткодов CPM, но не при обработке REST API-запроса.

## Инициализация менеджера модуля

Каждый менеджер модуля создаётся в классе Plugin при выполнении хука `init`, поэтому любые действия в конструкторе любого менеджера модуля уже выполняются по хуку `init` WordPress.

## Реализация

Все свойства и методы класса `Base_Manager` проектируются и реализуются исходя из технической необходимости. Техническое задание не ограничивает реализацию этого класса специальными требованиями.
