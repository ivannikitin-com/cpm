# Классы CPM v3: полный список, пространства имён, пути файлов

Источник: заметка «Классы CPM v3». Если какой-то класс не описан детально, его реализация должна выполняться в соответствии со стандартами кодирования (`docs/09-стандарты-кодирования.md`).

## Пространства имён

- Все классы находятся в базовом пространстве имён `\CPM\v3\`.
- Каждый модуль использует своё подпространство: ядро — `\CPM\v3\Core\`, REST API — `\CPM\v3\REST\`, UI — `\CPM\v3\UI\`, расширения — `\CPM\v3\Extensions\` (уточняется при реализации модулей).

## Основные классы и расположение файлов

Все файлы классов располагаются в папке `classes` в папке плагина (в документации — `CPM_PLUGIN_DIR`).

| Класс | Пространство имён | Файл | Статус спецификации |
| ----- | ----------------- | ---- | ------------------- |
| `Plugin` | `\CPM\v3` | `CPM_PLUGIN_DIR/classes/plugin.php` | описано |
| `Settings` | `\CPM\v3` | `CPM_PLUGIN_DIR/classes/settings.php` | минимально (см. `04-settings.md`) |
| `Base_Manager` | `\CPM\v3` | `CPM_PLUGIN_DIR/classes/base_manager.php` | описано |
| `Core_Manager` | `\CPM\v3\Core` | `CPM_PLUGIN_DIR/classes/core/core_manager.php` | описано |
| `REST_API_Manager` | `\CPM\v3\REST` | `CPM_PLUGIN_DIR/classes/rest_api/rest_api_manager.php` | минимально |
| `UI_Manager` | `\CPM\v3\UI` | `CPM_PLUGIN_DIR/classes/ui/ui_manager.php` | минимально |
| `Extensions_Manager` | `\CPM\v3\Extensions` | `CPM_PLUGIN_DIR/extensions/extensions_manager.php` | минимально |

> Примечание: в исходной заметке для `Settings` указан файл `classes/sessings.php` (опечатка) и для `UI_Manager`/`Extensions_Manager` повторно ошибочно назван класс `REST_API_Manager`. Выше — исправленные варианты.

## Классы ядра `\CPM\v3\Core`

Все файлы и классы ядра располагаются в `CPM_PLUGIN_DIR/classes/core`. Полный перечень и карта — в `docs/core/README.md`.

## Назначение менеджеров модулей

- `Plugin` — инициализация плагина и его модулей (создаёт экземпляры менеджеров по хуку `init`).
- `Settings` — хранение, доступ и интерфейс работы с настройками CPM.
- `Base_Manager` — базовый класс для всех менеджеров модулей.
- `Core_Manager` — менеджер ядра: загрузка классов ядра, регистрация CPT, фабрика сущностей, ACL.
- `REST_API_Manager` — менеджер REST-контроллеров сущностей.
- `UI_Manager` — менеджер модуля пользовательского интерфейса.
- `Extensions_Manager` — менеджер расширений системы.
