# Класс Settings

> Спецификация минимальна: в источниках класс `Settings` упомянут только в общем списке классов. Реализация выполняется по стандартам кодирования.

Класс `\CPM\v3\Settings` обеспечивает:

- хранение настроек CPM;
- доступ к настройкам;
- реализацию интерфейса работы с настройками CPM.

## Замечания

- Файл: `CPM_PLUGIN_DIR/classes/settings.php`.
- Способ хранения (options API WordPress, мета, отдельные страницы) на этапе проектирования не зафиксирован — решить при реализации.
- Хук `cpm_settings_backward_compatibility` (см. `docs/core/совместимость.md`) связан с настройками и должен учитываться при проектировании интерфейса настроек.
