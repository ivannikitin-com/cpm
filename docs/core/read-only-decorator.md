# Класс ReadOnly_Decorator

Декоратор, который **запрещает любые модификации** сущности. Чтение всех методов и свойств проходит без ограничений.

Наследуется от `Base_Decorator`.

## Поведение

- `can_modify()` всегда возвращает `false` — модификация (сохранение, удаление, изменение свойств) запрещена.
- Все операции чтения (`get_project()`, `get_type()`, чтение свойств) делегируются обёрнутой сущности без ограничений.
- `save()` и `delete()` не выполняют изменений в БД (выбрасывают `AccessDeniedException`).

## Использование

Применяется для сущностей, доступных только для чтения, например:

- Проект (для `MANAGER`, `CO_WORKER`, `CLIENT`);
- Список задач (для `MANAGER`, `CO_WORKER`, `CLIENT`);
- Активность (для `MANAGER`, `CO_WORKER`).

См. таблицу прав в `права-и-роли.md` и логику выбора декоратора в `core-manager.md`.

## Пример реализации `can_modify()`

```php
protected function can_modify() {
	return false;
}
```
