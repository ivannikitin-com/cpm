# Мета-поля CPM v3

**Нормативный справочник** всех мета-полей WordPress, используемых сущностями CPM v3. Сводит воедино мета-ключи, разбросанные по описаниям классов, и является источником истины для реализации `get_wp_args()`, SQL-запросов и миграции.

Все данные CPM v3 хранятся штатными средствами WordPress в мета-полях записей (`postmeta`). Исключение — таблица `in_cpm_user_role` старой версии, используемая только для обратной совместимости при чтении.

## Сводная таблица мета-полей

| Мета-ключ | Сущность(и) | Тип | Описание |
| --------- | ----------- | --- | -------- |
| `_team` | Все сущности | строка | Участники сущности в формате `"user_id":role,...` (см. `права-и-роли.md`) |
| `_thumbnail_id` | Все, кроме Comment | int | ID вложения-картинки (featured image), `0` = нет |
| `_cpm_coordinator` | Project | int | Координатор проекта (Product Owner) |
| `_project_active` | Project | строка | Статус проекта: `yes` / `no` |
| `_start` | Task | строка | Дата/время старта задачи |
| `_due` | Task, Milestone | строка | Дата/время срока |
| `_completed` | Task, Milestone | int | Признак завершения: `1` / `0` |
| `_completed_on` | Task | строка | Дата/время завершения |
| `_completed_by` | Task | int | ID пользователя, завершившего задачу |
| `_task_privacy` | Task | строка | Приватность задачи: `yes` / `no` |
| `_doc_type` | Note | строка | Тип заметки: `_custom_doc` / `_google_doc` |
| `_project_uploaded` | Note | int | ID проекта, к которому относится заметка (совпадает с `parent`) |
| `_message_privacy` | Message | строка | Приватность обсуждения: `yes` / `no` |
| `_milestone` | Message, Task_List | int | ID вехи; `0` (Message) / `-1` (Task_List) = веха не назначена |
| `_files` | Message, Comment (commentmeta) | сериализ. массив | ID вложений (attachment), прикреплённых к обсуждению или комментарию |
| `_project` | Attachment | int | ID проекта, к которому относится вложение |
| `_parent` | Attachment | int | ID сущности, к которой прикреплено вложение |

## Не используемые в v3 ключи (легаси)

| Ключ | Комментарий |
| ---- | ----------- |
| `_project_archive` | Архивный проект старой версии, **НЕ используется** в v3 (заменён `_project_active`) |
| `_assigned` | Участники задачи старой версии, читается только для обратной совместимости и конвертируется в `_team` |

## Зарезервированный штатный ключ

- `_thumbnail_id` — **штатный** ключ WordPress для featured image. Его использует встроенный API (`set_post_thumbnail()`, `get_post_thumbnail_id()`), поэтому он не является «собственным» мета-ключом CPM.

## Штатные поля записи (не мета)

Часть данных сущности хранится не в мета-полях, а в стандартных колонках таблицы `posts`:

| Поле записи | Свойство сущности | Описание |
| ----------- | ----------------- | -------- |
| `post_title` | `title` | Заголовок |
| `post_content` | `content` | Содержимое (Markdown) |
| `post_author` | `author` | Автор |
| `post_date` | `created_at` | Дата создания |
| `post_name` | `slug` | Слаг (часть URL) |
| `post_parent` | `parent` | ID родительской сущности |
| `menu_order` | `menu_order` | Позиция для сортировки |
| `post_type` | — | CPT сущности (`cpm_project`, `cpm_task` и т.д.) |

## Правила использования

- **Приоритет нового формата**: если для сущности данные есть и в старом формате (таблица `in_cpm_user_role`, ключ `_assigned`), и в новом (`_team`), при чтении используется только новый формат. Это реализуется `COALESCE()` в SQL-запросах.
- **Запись всегда в новом формате**: сохранение участников и прочих данных всегда выполняется только в мета-полях новой версии.
- Мета-ключи имеют префикс `_`, кроме штатного `_thumbnail_id`.
- Роли `ADMINISTRATOR` и `NO_ROLE` в БД **не сохраняются** (определяются динамически).
