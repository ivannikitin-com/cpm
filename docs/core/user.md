# Класс User

Класс `\CPM\v3\Core\User` хранит информацию о пользователе и при необходимости загружает её из БД. **Класс НЕ должен обновлять БД.**

## Свойства

| Свойство | Тип | Назначение |
| -------- | --- | ---------- |
| `id` | int | Идентификатор пользователя WordPress |
| `role` | int/string | Роль пользователя, значения из констант `ACL` |
| `name` | string | Имя пользователя, берётся из `display_name` |
| `avatar` | string | Аватар пользователя, берётся из `WP_User` |

## Методы

| Метод | Назначение |
| ----- | ---------- |
| конструктор `__construct($id, $role)` | Заполняет обязательные поля. **НЕ вызывает `load()`.** Загрузка данных из `WP_User` только по требованию |
| `get_name()` | Возвращает имя пользователя. Если свойство `name` пустое, сначала выполняет `load()` |
| `get_avatar()` | Возвращает аватар пользователя. Если свойство `avatar` пустое, сначала выполняет `load()` |
| `load()` (protected) | Читает свойства `name` и `avatar` из WordPress `WP_User` по `id`. Если пользователь не найден, выбрасывает исключение `BadUserException` |

> `BadUserException` — часть иерархии исключений ядра. См. `ошибки.md`.
