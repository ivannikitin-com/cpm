# Класс Modify_Decorator

Декоратор, который **разрешает любые модификации** сущности.

Наследуется от `Base_Decorator`.

## Поведение

- `can_modify()` всегда возвращает `true` — модификация (сохранение, удаление, изменение свойств) разрешена.
- Все операции полностью делегируются обёрнутой сущности.
- `save()` и `delete()` выполняются без ограничений.

## Использование

Применяется для сущностей, где пользователю разрешена полная модификация, например:

- Задача (для `MANAGER` — `modify`);
- Проект (для `MANAGER` — `modify*`, кроме удаления самого проекта; удаление контролируется отдельно в `delete()` проекта, см. `project.md`).

См. таблицу прав в `права-и-роли.md` и логику выбора декоратора в `core-manager.md`.

## Пример реализации `can_modify()`

```php
protected function can_modify() {
	return true;
}
```
