# Представление контента сущности CPM

> **Граница ответственности: ядро не парсит контент.**
> Ядро CPM **не занимается парсингом** Markdown, HTML или шорткодов. Оно лишь хранит и возвращает `content` сущности как строку (в исходном формате). Парсинг, преобразование в HTML и отображение выполняет **модуль интерфейса (UI)**.
>
> Этот документ описывает форматы хранения и правила, которые UI должен учитывать при отображении.

Любая сущность (Project, Task_List, Task, Comment, Message, Milestone, Attachment) имеет текстовое представление.

В старой версии это текст, возможно с шорткодом или HTML (для комментариев). В новой версии — **Markdown**.

## Признаки отличия форматов хранения

- Если строка начинается с `<div>`, то это HTML.
- Если строка начинается с `[cpm_` или `Задача [cpm_`, то это текст с шорткодом.
- Во всех остальных случаях считать содержимое форматом Markdown.

## Преобразования старых форматов

Преобразование выполняется **только при сохранении сущности**.

Правила преобразования к новому формату:

1. HTML не преобразуется, а остаётся в том виде, в котором он есть.
2. Текст с шорткодом преобразуется так:
   1. `[cpm_user_url id="XXX"]` — извлекается `XXX`, считывается `display_name` пользователя с ID `XXX`; этим заменяется шорткод.
   2. `[cpm_tasklist_url id="XXX" project="YYY" title=""]` — запрашивается объект Task_List с ID `XXX`; шорткод заменяется на `title` этой сущности.
   3. `[cpm_task_url id="XXX" project="YYY" list="ZZZ" title="TTTT"]` — запрашивается объект Task с ID `XXX`; шорткод заменяется на `title` этой сущности.

## Правила отображения текста в UI

1. HTML выводится как есть.
2. Вместо шорткодов выводится первый идентификатор `XXX`.
3. Markdown выводится с помощью парсера Markdown.

## Открытые вопросы

- [ ] Уточнить, где именно выполняется преобразование старых форматов: в `get_wp_args()` при сохранении (ядро) или при чтении (UI). По умолчанию предполагается `get_wp_args()` в `Entity`.
- [ ] Обратный процесс: как UI определяет, что строка является Markdown/HTML/шорткодом, и где выполняется парсинг (предположительно в UI).
