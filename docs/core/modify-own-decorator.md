# Класс ModifyOwn_Decorator

Декоратор, который **запрещает модификацию чужих сущностей** и разрешает модификацию только тех, которые созданы текущим пользователем.

Наследуется от `Base_Decorator`.

## Поведение

- `can_modify()` возвращает `true`, только если текущий пользователь является **автором** сущности, то есть `$this->entity->author === текущий пользователь`.
- Для чужих сущностей модификация запрещена, чтение разрешено.
- `save()` и `delete()` выполняются только для своих сущностей.

## Использование

Применяется для сущностей с правом `modify_own`, например:

- Комментарий (для `MANAGER`, `CO_WORKER`, `CLIENT`);
- Обсуждение `Message` (для `MANAGER`, `CO_WORKER`, `CLIENT`);
- Задача (для `CLIENT` — `modify_own`).

См. таблицу прав в `права-и-роли.md` и логику выбора декоратора в `core-manager.md`.

## Пример реализации `can_modify()`

```php
protected function can_modify() {
	$user_id = get_current_user_id();
	return (int) $this->entity->author === (int) $user_id;
}
```
