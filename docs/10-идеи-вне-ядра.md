# Идеи вне ядра

Зафиксированные в источниках идеи, которые не относятся к ядру CPM и не имеют пока спецификации. Реализуются только по отдельному решению.

## AI в CPM

Идея интеграции CPM v3 с искусственным интеллектом (ChatGPT 4o mini):

- высокая скорость работы;
- низкая стоимость;
- лёгкость интеграции через OpenRouter.

Сценарий использования — постановка задачи в CPM через AI.

## Пригласительные ссылки

Идея пригласительных ссылок в проект для представителей и клиентов:

- при переходе по ссылке проверяется наличие пользователя;
- при необходимости пользователь создаётся и добавляется в проект;
- при создании пользователя на почту отправляется инструкция.
